# 使用指南

[English](usage.md) · 简体中文

## 文本与 HEX 控制

三个 HEX 开关相互独立：

| 控件 | 作用 |
| --- | --- |
| 接收 HEX 显示 | 改变日志中数据内容的显示方式。 |
| 发送框右上角 `H` | 在文本与 HEX 之间显示、转换当前草稿。 |
| 接收工具栏中的 HEX 发送模式 | 决定将草稿编码为 UTF-8 文本，还是解析为 HEX 字节发送。 |

HEX 使用空格分隔的两位字节，例如 `0A FF 1B`。文本模式可选择不追加换行、追加 CRLF（`\r\n`）或 LF（`\n`）；HEX 模式直接发送解析后的字节，不追加文本换行。HEX 转回文本时，字节必须是有效的 UTF-8。

## ANSI 颜色

文本模式下，接收到的 ANSI 转义序列会被渲染而不是显示为乱码：支持 SGR 颜色（16 色、256 色、24 位真彩色）、
粗体、暗淡、斜体、下划线、删除线和反色；其余转义序列（光标移动、清屏、标题等）会被丢弃。
转义字节不会出现在显示文本中，因此搜索、过滤、复制和保存得到的都是纯文本。
样式只在单条日志内生效，不会延续到下一条。HEX 模式始终显示原始字节（包括 `1B`）。

## 发送历史

在发送框中光标位于第一行时按 `↑`，会调出上一条发送过的内容，继续按可继续回溯；
在最后一行按 `↓` 向后翻，翻过最新一条后恢复回溯前正在输入的内容。
空内容和与上一条相同的内容不会被记录。历史按会话保存（最多 100 条），不会写入磁盘；
只记录从发送框发出的内容，不包括快捷发送和定时发送。

## 复制与选择日志

在日志上按住左键拖动即可选中文本，再用常规快捷键复制。双击选中一个词，三击选中整条记录，之后拖动会按词或按条扩展；
Shift+点击可扩展当前选区；单击不拖动会清除选区。拖选时把鼠标停在日志区上沿或下沿附近、
或移到区域之外，列表会持续滚动并延伸选区；鼠标越靠外滚动越快。这样向上滚动会像手动滚动一样
关闭自动滚动。选区可以跨越任意多屏，复制时会取全部被选中的记录，包括已经滚出视野的。
清空日志、应用过滤、切换时间戳或 HEX 显示时选区会被清除；日志缓冲淘汰最旧记录时，选区的起点会相应收到最早保留的记录。

接收工具栏里保存按钮旁的 **复制全部** 按钮可一键把当前显示的所有条目放入剪贴板，内容与“保存”写出的
完全一致：遵循时间戳与 HEX 设置，过滤开启时只复制通过过滤的条目。复制后图标会短暂变成对勾；日志为空
时不会改动剪贴板。

窗口顶部的条带除了正中的一个小手柄（一条浅色小白条，用于拖动窗口）外都不拦截鼠标，因此不会遮挡日志文字。

## 日志过滤

点击接收工具栏中搜索旁的过滤图标，在同一个工具栏面板内向上展开或收起过滤区，
过滤区与工具按钮共用背景和外框。
点击方向按钮，在「全部 → RX → TX → 脚本 → 全部」之间循环切换，默认显示全部（「脚本」只显示脚本打印的行）。
方向、关键词和下面的选项的修改先保存在草稿中，点击**应用**或在关键词框中按 Enter 后才生效；
草稿与当前生效的过滤不同时，**应用**按钮高亮。
`Aa` 开启大小写敏感，`.*` 开启正则表达式，`≠` 排除匹配内容（例如心跳包），
三个选项默认关闭。未开启正则时，关键词作为一个完整的普通字符串匹配；
关键词为空时不限制正文，即使开启排除也是如此。方向与正文条件必须同时满足。
过滤以当前缓存中的整条日志为单位，不跨记录匹配，也不按屏幕折行拆分。

只匹配正文，不匹配时间戳和方向标签。文本视图匹配显示的文本；HEX 视图匹配
带空格的 HEX 显示文本，例如 `AA 55`，输入 `AA55` 不会匹配 `AA 55`。
正则也作用于该显示文本，不直接匹配原始字节。切换文本/HEX 视图会重新过滤。
正则无效或过于复杂时显示错误，并继续使用上一次完整有效的条件处理缓存和新数据。
`↺` 重置方向及所有正文选项并立即生效。过滤生效时，主区域（不含底部状态栏）会被一圈强调色边框包住：
顶部（标题栏位置）标明“过滤模式”以及已过滤和显示的条数，内容会缩小着收进边框内（开启和关闭时有约 0.2 秒的过渡）。内容卡片的外沿有一圈细线，一段带渐隐拖尾的亮线沿着它不停绕圈跑动，表示过滤正在生效；系统开启“减少动态效果”时，只显示静止的细线。工具栏上的过滤按钮同样高亮并带一个小圆点。
收起过滤区后，过滤和高亮仍然生效。

各会话独立保存过滤条件，切换标签时保留，重启应用后重置。搜索、选区复制、复制全部和保存
只处理过滤后可见的记录。清空会删除**全部显示缓存记录，包括被过滤隐藏的记录**，
但保留过滤条件和字节计数。过滤不影响串口接收、暂停缓存、Lua 接收或流输出
（包括流输出开始时的缓存快照）。Lua `output.print` 的内容以 `LUA` 标签显示在接收区；
Lua 的 `print` / `log.*` 调试行只有在「设置 → 通用 → 脚本调试日志」打开时才显示，标签为 `LOG`、`WARN`
或 `ERR`；两者都属于「脚本」方向。连接错误仍在状态提示中展示。新数据会实时更新过滤结果；自动滚动仅跟随可见记录的变化。

## 日志标记

在接收日志里右键某一条，就可以给它打标记。弹出的小窗里填**名称**（最多 32 个字符）并选择八种**颜色**之一；
点**确定**（或按 `Enter`）后整条日志按该颜色高亮，`Esc` 或点击小窗外部则关闭小窗。标记属于日志里的一行
（一行接收内容或一次发送），会高亮这一整行。右键已标记的条目可以改名、换色或移除标记。

- **缩略条**：日志右侧的窄条替代了传统滚动条，同时展示可拖动的当前视口滑块以及被标记条目在整段可见日志中的位置。
  拖动滑块或点击空白轨道可快速定位（离开底部时会自动关闭自动滚动，避免新数据把视图拉回底部），点击彩色色块则直接跳转到对应条目。
- **标记区块**：右侧栏**快捷发送**下方列出本会话的全部标记，显示名称、颜色、时间戳和方向。点击一行可滚动到该条，
  铅笔图标用来编辑，`×` 用来移除；标题栏的 `×` 可清除全部标记（需确认）。被日志过滤隐藏的条目仍在列表里，
  但会置灰且不可点击，也不会出现在缩略条上，取消过滤后恢复。区块可以折叠，右侧栏很窄时会隐藏。

标记只保存在当前会话的内存里：不写入 `config.toml`，不会出现在导出文件和实时流输出中，清空日志或日志缓冲区上限
淘汰掉被标记的条目时，对应标记也会消失。

## 流量监控

点击底部状态栏右侧的 `RX / TX` 字节计数区域，可打开独立的流量监控窗口。窗口自动跟随主窗口当前选中的会话标签，
以 `4 Hz` 采样绘制实时接收（RX）和发送（TX）速率曲线（最多保留 5 分钟历史），并展示当前速率、窗口峰值、
累计字节数以及基于当前串口帧格式的理论带宽占用率。点击顶部摘要卡片可切换对应曲线显隐，支持切换
`30s` / `1m` / `5m` 时间视野、悬停十字准星查看精确数值、暂停画面和清空曲线历史。

## 实时流输出

点击接收工具栏里的持续保存按钮（带箭头的文件图标），在文件选择器中指定输出路径；已有文件会追加写入，原内容不会被覆盖。按钮高亮时正在记录，悬停可查看路径，再次点击停止。每个会话独立记录；同一文件同时只能由一个会话使用，不记录 Lua 的 `print` / `log.*` 调试输出，但会记录 `output.print` 的内容。

在**设置 → 常规 → 流输出范围**选择“当前缓存及后续”或“仅开始后”（默认）。前者在文件准备就绪时保存所属会话当时仍保留的可见及暂停缓存，再连续记录后续日志；不会恢复已清空或裁剪的历史，也不会包含其他会话。后者仅记录文件准备就绪并开始捕获后的日志。选项全局持久化，修改仅影响下一次开始，不会向正在记录的文件重复回填。

输出固定使用启用时的接收文本/HEX模式。文本模式按设备的 LF/CRLF 换行组织日志，每行只在开头添加首次字节的时间戳、RX/TX方向；连续 RX 分块接在同一行，尚未换行的内容也会实时写入。方向变化时会分隔未完行，TX事件分别记录，停止时为未完行补换行。文本按 UTF-8 增量解码，正常中文、CR/LF、制表符和反斜线保留；NUL及其他控制字节显示为 `\0`、`\xHH`，无效 UTF-8 字节也会转义。跨块字符最多暂存末尾3字节等待补全，停止或切换方向时未完整字符转为字节转义。二进制数据建议启用前切换 HEX，HEX模式仍按每次收发事件记录完整字节。

新建或空文件写入一次 UTF-8 BOM，帮助 Windows 编辑器识别编码；追加非空文件不会插入中途 BOM，也不会修改旧内容。带 UTF-16/UTF-32 BOM 的文件会明确拒绝追加，请选择新文件。之前无 BOM 且出现乱码的日志不会自动修复，请更换新文件后记录。

文件在后台持续写入，每条记录立即刷新应用缓冲；暂停显示、清空日志、缓存裁剪、切换标签和断线都不会停止记录。停止时在后台排空已排队记录；关闭会话会等待排空，正常退出应用会在框架退出等待期内排空。写入错误或后台队列满会停止捕获并在工具栏上方提示；修复路径或存储问题后可重新启用。

## 快捷发送

**快捷发送**区块位于右侧栏**脚本**区块下方。每条命令保存 `id`、`name`、可选 `group`、`content`、`hex` 与 `line_ending`（`"none"` / `"crlf"` / `"lf"`，开启 `hex = true` 时忽略））与 `checksum`（默认 `"none"`，可选 `"sum8"` / `"xor8"` / `"crc8"` / `"crc16_modbus"` / `"crc16_ccitt"` / `"crc32"`；仅在 `hex = true` 时把校验字节追加到解析后的字节之后；CRC-16/Modbus 低字节在前，其余多字节校验高字节在前）。点击命令会按其自带的 HEX 与换行符设置直接发送，不会改动发送卡输入框和底栏状态；在工作区按 `Alt+1` … `Alt+9`（修饰键可在[快捷键](#快捷键)中修改）可发送展示顺序中的前 9 条命令（跨分组计数，不受搜索过滤或折叠影响）。命令在所有会话间共享，并持久化在 `config.toml` 中：

```toml
[[quick_commands]]
id = "qc-1"
name = "AT"
group = "设备初始化"
content = "AT"
hex = false
line_ending = "crlf"

[[quick_commands]]
id = "qc-2"
name = "Ping"
group = "设备初始化"
content = "AA 55 01"
hex = true
```

`config.toml` 中单条格式损坏或 `id` 重复的命令会在加载时被忽略，不影响其余配置，并在快捷发送区块内提示。

## 定时发送

发送卡底部行中，发送按钮左侧常驻一个胶囊 `[⏱ | 1000 ms]`，用于按固定间隔重复发送输入框内容。点击左侧时钟图标只切换“启用”（进入或退出定时发送模式），不会直接发送；右侧为间隔输入（10 ~ 3600000 毫秒的整数），会记住上次使用的值（写入 `config.toml` 的 `timer_interval_ms`）。未连接时胶囊置灰，无法启用。

三种状态：

- **未启用**：胶囊为灰色描边、透明底，发送按钮是普通发送 `↑`。
- **已启用（待机）**：胶囊为强调色实心底，发送按钮变为播放 `▶`；点击播放（或在输入框按 Ctrl+Enter）开始定时发送，先校验间隔草稿与内容，无效则报错且不启动。
- **运行中**：图标带呼吸点，发送按钮变为暂停 `⏸`；点击暂停停止发送但保持启用，按钮回到 `▶`。运行中在输入框按 Ctrl+Enter 会被忽略并提示，不会当作暂停。再次点击时钟图标会取消启用（运行中则同时停止）。

开始后立即发送一次，之后按固定节拍发送；程序卡顿时错过的周期会被跳过，不会补发。若端口写入速度跟不上间隔（如低波特率），待写入的定时发送超过上限时同样跳过周期，避免堆满发送队列。

- 已启用期间（含待机）不能手动发送：输入框的普通发送、`Alt+1` … `Alt+9` 与快捷发送面板都不会发送并给出提示；脚本发送不受影响。
- 输入框内容、HEX 开关、底栏 HEX 发送与换行符可在运行中修改，从下一个周期起生效。间隔输入框中的内容是草稿：按回车或输入框失焦时才提交并从下一个周期起生效（未提交时输入段有淡淡的高亮），回车只提交不会启动；无效草稿会恢复为上一个有效间隔并提示。
- 每个周期发送前都会重新校验：内容为空或 HEX 格式非法时自动停止并提示，胶囊保持启用，可修正后再点播放。
- 点击暂停、写入失败，或发送队列被脚本、快捷发送占满时停止并提示（保持启用）；断线、关闭会话或取消启用会同时取消启用并停止，重新连接不会自动恢复。启用状态按会话独立，不会持久化。

## 版本更新

Sasha 启动时会向 GitHub Releases 检查一次更新（可在**设置 → 通用 → 检查更新**中关闭），也可在**设置 → 关于 → 检查更新**中手动检查。检查只会请求 GitHub API，不发送其他数据。发现新版本时，侧栏**设置**旁会出现一个圆点。

点击**下载并安装**会下载 Release 中的可执行文件，校验 SHA-256 后替换当前程序并提示重启，旧文件会在下次启动时清理。应用内安装要求该 Release 包含 `sasha-windows-x86_64.exe` 及其校验值（GitHub 资产摘要，或 `sasha-windows-x86_64.exe.sha256` 文件），且程序所在目录可写；否则可通过**更新说明**手动下载。版本按语义化版本比较，因此 `0.0.1-b` 早于 `0.0.1`。

## 偏好设置

从右侧栏打开**设置**。偏好保存在可执行文件同目录的 `config.toml` 中，设置页会显示实际配置路径。

```toml
version = 1
locale = "zh-CN"
log_font_size = 14
stream_output_scope = "future_only" # 或 "current_buffer_and_future"
theme = "dark"                # 内置 id 或 themes/ 中的文件名
```

语言支持 `en-US` 和 `zh-CN`，默认为 `zh-CN`。日志字号预设为 12、13、14、15 逻辑像素。`log_wrap` 决定超出日志区宽度的行如何换行：`"anywhere"`（默认）在任意两个字符之间都可以断开，每一行都会被填满，适合文件路径这类较长的连续文字；`"words"` 只在空格、`/` 等位置断开，较长的连续文字会整体移到下一行，可能留下较大的空白。也可以在 **设置 → 视图 → 日志换行方式** 中修改，立即生效；无法识别的值会回退为 `"anywhere"`。此文件不恢复会话草稿和连接状态。如果 TOML 格式损坏，Sasha 会尝试备份为 `config.toml.bak`，并回退到默认配置。

## 快捷键

**设置 → 快捷键** 列出了可以修改的快捷键。点击某一行的**修改**，再按下新的组合键（`Esc` 取消）；
**默认**恢复这一行，**全部恢复**恢复所有行。修改立即生效，并保存在 `config.toml` 中。

| 动作 | 默认键位 | 可修改内容 |
| --- | --- | --- |
| 新建会话 | `Ctrl+T` | 整个键 |
| 关闭会话 | `Ctrl+W` | 整个键 |
| 下一个会话 | `Ctrl+Tab` | 整个键 |
| 上一个会话 | `Ctrl+Shift+Tab` | 整个键 |
| 打开日志搜索 | `Ctrl+F` | 整个键 |
| 跳转到第 1–9 个会话 | `Ctrl+1` … `Ctrl+9` | 仅修饰键 |
| 发送第 1–9 条快捷命令 | `Alt+1` … `Alt+9` | 仅修饰键 |

两个 1–9 的行，请按下修饰键加任意一个数字，例如 `Ctrl+Alt+1`，只保留修饰键。`Ctrl+9` 跳转到最后一个会话。
被编辑操作和系统占用的键是保留键，会被拒绝：`Enter`、`Esc`、`F3`、`Alt+F4`，以及 `Ctrl`/`Cmd` 加 `A`、`C`、`V`、`X`、`Z`、`Y`。

规则：快捷键必须带 `Ctrl`、`Alt` 或 `Cmd`（只有 Shift 不行），两个动作不能用同一个键。键位已被占用时会拒绝，
并在提示里写出占用它的动作。跳转会话的修饰键是 `Ctrl` 时，单个键也不能设为 `Ctrl+1` … `Ctrl+9`。

```toml
[shortcuts]
new_session = "ctrl-n"
close_session = "ctrl-w"
next_session = "ctrl-tab"
prev_session = "ctrl-shift-tab"
search = "ctrl-f"
jump_session = "ctrl"
quick_send = "ctrl-alt"
```

取值用小写并以 `-` 连接；单个键最后一段是键名（`t`、`tab`、`f3`），两个 1–9 的行只写修饰键
（`ctrl`、`alt`、`shift`、`cmd`）。缺失、无效、保留或冲突的项保持默认值；如果默认值又与你的某个自定义键冲突，相关的自定义项也会回到默认，其余保留。
其他设置不受影响。
